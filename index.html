Radio and channel
Propagation
Rain: ITU-R P.837 zone rate, P.838-3 specific attenuation, P.530-17 path reduction and percentage scaling. Gases: P.676 Annex 2.
Terminal units (TU)
New TUs get the default antenna. You can change it per TU from its popup.
Interference
Antenna model: 3GPP TR 38.901 horizontal pattern, G(φ) = Gmax − min(12·(φ/φ3dB)², F/B). AP φ3dB = sector beamwidth; TU φ3dB = 30° or 45°. All co-channel sectors are assumed to transmit downlink at the same time (synchronised TDD), interferer paths are assumed LoS, adjacent-channel leakage is ignored.
Terrain and line of sight
Elevation data is a bare-earth model (Copernicus 90 m / SRTM). Buildings and trees are not in it, so set a clutter height for urban areas. Paths with missing elevation data are flagged “LoS unverified”, not treated as clear.

User capacity per MCS and bandwidth (Mbps)

PHY model mirrors wifi7Radio: rate = tones × bits × coding rate / (12.8 µs + GI); threshold RSL = −114 + 10·log10(BW) + NF + SNR(MCS). A link closes at an MCS when RSL − threshold ≥ margin.
